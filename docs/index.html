How it works

How the league works · scoring, seasons, ranking, and identity, all explained on one page.

A note on the averages: MTGO publishes standings only to 32nd place. Every average on this site is therefore computed from a pilot's better results. It shows how a pilot does when they do well, not how they do overall.

Game win % is not a win rate: it counts individual games, not matches, and is shown only as a per-event figure averaged across a pilot's recorded Top 32 results.

A pilot who would like to be removed from this public table may ask, and it will be done.
